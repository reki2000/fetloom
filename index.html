      .fetl syntax
      
    

    

      
Modules and connections

      
Define a module with inputs before -> and outputs after it. Calls connect ports in their declared order: inputs, then outputs. Semicolons are optional.

      
module inv(a -> y) {
  Pmos(a, Vcc, y)
  Nmos(a, y, Gnd)
}

module main(a -> y) {
  inv(a, y)
}

      
Module names use lowercase or snake_case. Select the top module in the simulator; examples use main. The arrow can be omitted when a module has no outputs.

      
Signals and buses

      
Ports name the module's signals. Names starting with _ create local wires without a declaration. Other undeclared signal names are errors. Vcc and Gnd are global logic 1 and 0.

      
module and2(a, b -> y) {
  nand2(a, b, _n)
  inv(_n, y)
}

      
Declare a bus with its width, such as a[4]. In a call, a connects the whole bus and a[0] selects a bit. Bit 0 is least significant. Local bus widths are inferred from connected ports; first use a local bus where its width is known.

      
module invert4(a[4] -> y[4]) {
  inv(a[0], y[0])
  inv(a[1], y[1])
  inv(a[2], y[2])
  inv(a[3], y[3])
}

      
Built-in elements

      

        
SyntaxBehavior

        
          
Nmos(gate, a, b)Connects a and b when gate is 1.

          
Pmos(gate, a, b)Connects a and b when gate is 0.

          
Cap(net)Retains the last stable 0/1 when undriven.

          
Clk(halfPeriod, out)Square wave; halfPeriod is measured in ticks.

          
Rom("file.hex", addr, data)Asynchronous ROM read from hexadecimal bytes.

          
Ram(addr, din, dout, we, clk)Asynchronous read; writes on a rising clock edge when we is 1. Input and output data widths must match.

        
      

      
Gates, adders, multiplexers, and registers are user modules built from these elements.

      
Comments and values

      
// Line comment
# Another line comment
/* Block comment */

      
Numeric arguments accept decimal or hexadecimal integers, such as 8 or 0x10. File paths use double quotes. Nets carry 0, 1, Z (undriven), or X (unknown/conflicting).

      
Write connections as calls; expressions, assignments, loops, and imports are not supported. main.q[*] is a numeric-group selector in the UI, not .fetl source syntax.
