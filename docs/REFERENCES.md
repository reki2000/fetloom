# 4004 references used for the sample

- Intel MCS-4 Users Manual, instruction descriptions and DCL/JCN behavior: https://www.bitsavers.org/components/intel/MCS40/MCS-40_Users_Manual_Nov74.pdf
- Intel MCS-4 Assembly Language Programming Manual: https://www.bitsavers.org/components/intel/MCS4/MCS-4_Assembly_Language_Programming_Manual_Dec73.pdf
- Intel 4004 instruction summary: https://8bitforce.com/projects/4004/
- Intel 4004 operational-semantics/formalization project: https://github.com/CharlesCNorton/intel-4004-verified

The FetLoom sample uses the documented 46 instruction encodings, three-level subroutine behavior for normal nesting, JCN condition fields, SRC/DCL state, and the documented DCL CM-RAM line mapping. It is not a reproduction of the original physical transistor network.
